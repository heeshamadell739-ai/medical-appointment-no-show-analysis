# Dataset Reference

The dataset used in this project is the **Medical Appointment No Shows** dataset from Kaggle.

- **Dataset:** Medical Appointment No Shows
- **Source:** Kaggle
- **File:** `KaggleV2-May-2016.csv`

You can access the original dataset here:

https://www.kaggle.com/datasets/joniarroba/noshowappointments

This dataset is used for educational and exploratory data analysis purposes in this project.
